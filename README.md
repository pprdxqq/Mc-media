# MC Media — Website Redesign Concept

A responsive, multi-page redesign concept for MC Media, based on the public information and positioning on [mc-media.de](https://www.mc-media.de/).

## Pages
- `index.html` — homepage and positioning
- `leistungen.html` — employer branding, digital reach, application flow
- `erfolge.html` — selected public case studies
- `ueber-uns.html` — company story and approach
- `kontakt.html` — contact details and official enquiry route

## Design direction
- Dark navy, sea-glass teal and restrained lilac accents
- Glassmorphism dashboard and floating UI panels
- Neumorphic surfaces for cards and tactile controls
- Responsive navigation and mobile-first layouts
- Reduced-motion support and semantic page structure

## Run locally
Open `index.html` in a browser, or use any static server. No build step is required.

## Important
This is an independent redesign concept, not the official MC Media website. It does not submit form data. Contact actions link to MC Media's published phone, email and official enquiry page. Public case-study figures are reproduced as attributed summaries and should be reconfirmed with MC Media before public launch.

## Deployment
The repository is static-site ready for GitHub Pages or Vercel. Set the project root to the repository root and use no build command; the output directory is `.`.
